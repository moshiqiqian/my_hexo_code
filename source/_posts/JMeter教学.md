### JMeter 可添加组件总览

在 JMeter 里，右键 **测试计划** 或 **线程组**，菜单里的“添加”通常包含以下几大类：

| 类别                               | 作用                         | 常见组件                                                     |
| :--------------------------------- | :--------------------------- | :----------------------------------------------------------- |
| **线程（Users）**                  | 控制“谁来跑、跑多久、跑几次” | 线程组、setUp 线程组、tearDown 线程组、开放模型线程组        |
| **配置元件（Config Element）**     | 给请求提供公共配置           | CSV 数据文件设置、HTTP 信息头管理器、HTTP Cookie 管理器、HTTP 请求默认值、用户定义的变量 |
| **取样器（Sampler）**              | 真正发出请求                 | HTTP 请求、JDBC 请求、FTP 请求、TCP 请求、调试取样器         |
| **逻辑控制器（Logic Controller）** | 控制请求执行顺序             | 事务控制器、循环控制器、If 控制器、While 控制器、ForEach 控制器、Switch 控制器 |
| **前置处理器（Pre Processor）**    | 请求发出前做处理             | JSR223 前置处理器、BeanShell 前置处理器                      |
| **后置处理器（Post Processor）**   | 请求返回后做处理             | JSON 提取器、正则表达式提取器、XPath 提取器、边界提取器      |
| **断言（Assertion）**              | 判断响应是否正确             | 响应断言、JSON 断言、持续时间断言、大小断言                  |
| **定时器（Timer）**                | 控制请求间隔                 | 固定定时器、随机定时器、常数吞吐量定时器、同步定时器         |
| **测试片段（Test Fragment）**      | 可复用的测试模块             | 测试片段                                                     |
| **非测试元件（Non-Test Element）** | 辅助工具                     | HTTP 代理服务器、HTTP 镜像服务器                             |
| **监听器（Listener）**             | 收集和展示结果               | 聚合报告、查看结果树、汇总报告、用表格查看结果、后端监听器   |

### 压力测试的先后框架

一次完整的 JMeter 压测，组件按**执行顺序**和**逻辑层级**组织如下：

text

```
测试计划（Test Plan）
│
├── setUp 线程组（可选）
│   └── 登录 / 初始化数据
│
├── 线程组（主压测）
│   ├── 配置元件
│   │   ├── CSV 数据文件设置
│   │   ├── HTTP 信息头管理器
│   │   ├── HTTP Cookie 管理器
│   │   └── 用户定义的变量
│   │
│   ├── 逻辑控制器（可选）
│   │   └── 事务控制器 / 循环控制器 / If 控制器
│   │
│   ├── 前置处理器（可选）
│   │   └── JSR223 前置处理器
│   │
│   ├── 定时器（可选）
│   │   └── 固定定时器 / 同步定时器
│   │
│   ├── 取样器
│   │   └── HTTP 请求
│   │
│   ├── 后置处理器（可选）
│   │   └── JSON 提取器 / 正则表达式提取器
│   │
│   └── 断言（可选）
│       └── 响应断言 / JSON 断言
│
├── tearDown 线程组（可选）
│   └── 清理数据 / 退出登录
│
└── 监听器
    ├── 聚合报告
    └── 查看结果树（调试用）
```

### 执行顺序（从外到内）

JMeter 执行时，**同一层级内按从上到下顺序执行**，跨层级按以下顺序：

| 顺序 | 组件           | 说明                                |
| :--- | :------------- | :---------------------------------- |
| 1    | **配置元件**   | 先准备好配置（CSV、Header、Cookie） |
| 2    | **前置处理器** | 请求前处理数据                      |
| 3    | **定时器**     | 控制请求节奏                        |
| 4    | **取样器**     | 真正发请求                          |
| 5    | **后置处理器** | 提取响应数据                        |
| 6    | **断言**       | 校验响应                            |
| 7    | **监听器**     | 收集结果                            |

**记忆口诀：**

> **配置 → 前置 → 定时 → 取样 → 后置 → 断言 → 监听**

### 按功能归类总结

| 功能          | 对应组件                       | 常用度 |
| :------------ | :----------------------------- | :----- |
| 控制并发      | 线程组                         | 极高   |
| 准备数据      | CSV 数据文件设置               | 极高   |
| 设置请求头    | HTTP 信息头管理器              | 极高   |
| 发请求        | HTTP 请求                      | 极高   |
| 提取响应      | JSON 提取器 / 正则表达式提取器 | 高     |
| 校验结果      | 响应断言                       | 高     |
| 控制节奏      | 定时器                         | 中     |
| 控制流程      | 逻辑控制器                     | 中     |
| 查看结果      | 聚合报告 / 查看结果树          | 极高   |
| 前后置处理    | JSR223 处理器                  | 中     |
| 环境准备/清理 | setUp / tearDown 线程组        | 中     |

------

### 一句话总结

> **JMeter 压测的框架：**
> **setUp 打前站 → 线程组干正事（配置 → 前置 → 定时 → 取样 → 后置 → 断言）→ tearDown 搞卫生 → 监听器看结果。**
